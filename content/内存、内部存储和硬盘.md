买手机时，你可能见过 `12GB + 256GB`。有的商品页面把前者叫“运行内存”，把后者叫“机身内存”。等你打开电脑，系统又会分别显示“内存”和“磁盘”。

这些名称混在一起，很容易让人以为它们只是容量不同。其实，`12GB` 和 `256GB` 承担的是两种工作。

## 先记住三个结论

- **内存**（RAM）是程序运行时使用的临时工作区域。
- **内部存储**是设备内部长期保存应用、照片和文件的空间。
- **硬盘**是电脑存储设备的常用名称。常见的存储设备包括固态硬盘（SSD）和机械硬盘（HDD）。

把电脑想成一张书桌和一个文件柜：

- 内存像桌面。你把正在处理的材料摊在桌面上，拿取很快，但桌面面积有限。
- 存储像文件柜。你把暂时不用的材料收进柜子，关机后也能保留下来。
- “内部存储”表示文件柜放在设备里面。
- SSD 和 HDD 表示这个文件柜采用了不同的工作方式。

这个类比只用来说明“临时工作区域”和“长期保存空间”的区别。内存和存储都是电子硬件，不会真的按照书桌和文件柜的方式工作。

## 内存是什么

这里说的内存，通常指随机存取存储器（Random Access Memory，RAM）。

你打开浏览器、游戏或文档时，系统会把程序当前需要的数据放进 RAM。程序关闭后，系统可以把这部分空间交给其他程序。普通 RAM 需要持续供电，设备断电后，其中的数据不会像照片和文档那样长期保留。[^1][^2]

内存容量会影响设备能同时容纳多少正在运行的程序和数据。内存紧张时，系统可能关闭后台程序、压缩部分数据，或者把一部分数据临时转移到其他位置。不同操作系统采用的办法并不完全相同。[^1]

因此，8GB 内存和 16GB 内存的主要差别，不是“文件能保存多少”，而是设备运行程序时有多少工作空间。

## 内部存储是什么

内部存储是设备内部的长期保存空间。应用、照片、视频、下载内容和文档通常保存在这里。你正常关机或重启后，这些内容仍然存在。[^1][^3]

“内部存储”描述的是位置和用途，不是一种与内存、硬盘并列的特定硬件。

在手机和平板电脑上，内部存储通常使用闪存。在电脑上，设备内部的存储可能是 SSD，也可能是 HDD。Apple 的文档也把 Mac 的内部磁盘称为保存应用和资料的存储设备。[^4]

所以，“手机有 256GB 内存”这句话往往不够准确。它通常想表达的是：手机有 256GB 内部存储，可以用来保存应用和文件。

## 硬盘是什么

“硬盘”在日常中文里有两种用法。

严格按硬件名称来说，硬盘驱动器（Hard Disk Drive，HDD）指机械硬盘。它使用旋转的磁性盘片和读写磁头保存数据。

日常交流中，很多人也会把电脑里的 SSD 叫作“固态硬盘”，再把 SSD 和 HDD 统称为“硬盘”。SSD 通常使用闪存，没有 HDD 那样的活动机械部件。两者都能长期保存系统、软件和文件。[^5][^6]

为了减少误会，讨论具体硬件时可以直接说：

- **SSD**：固态硬盘；
- **HDD**：机械硬盘；
- **存储设备**：不需要区分具体类型时使用。

## 为什么这些词经常混在一起

英文单词 `memory` 可以泛指用于保存数据的存储，也可以在具体语境中指 RAM。中文商品页面还会使用“运行内存”“机身内存”“存储内存”等名称。

容量单位也帮不上忙。RAM、SSD 和手机内部存储都可以使用 GB 表示。只看数字后面的 `GB`，无法判断它属于哪一种空间。

看到 `12GB + 256GB` 时，常见的含义是：

- `12GB`：RAM，也就是运行内存；
- `256GB`：内部存储，也就是保存应用和文件的空间。

商品页面的写法并不统一。购买前应查看参数表中的完整名称，不要只看两个数字。

## 几个常见误会

### “手机有 256GB 内存”

这通常指 256GB 内部存储。手机的 RAM 往往是另一个数字，例如 8GB、12GB 或 16GB。

### “删除照片可以增加运行内存”

删除照片主要释放内部存储。照片占用的是长期保存空间，不是持续占用同等大小的 RAM。

应用在查看、编辑照片时仍可能把部分照片数据读入 RAM，但这不等于照片文件一直放在 RAM 里。

### “关闭应用可以腾出很多存储空间”

关闭应用主要影响 RAM。应用本身、缓存和下载的文件仍可能留在内部存储中。

如果你要释放存储空间，需要删除不再需要的文件、卸载应用，或者使用系统提供的存储管理功能。操作前先确认重要文件已经备份。

### “1TB SSD 可以弥补 8GB 内存不足”

1TB SSD 提供的是文件保存空间，不能变成同等容量的物理 RAM。

操作系统可以借用一部分存储空间缓解 RAM 紧张，但存储设备和 RAM 的速度、用途不同。这种办法不能把 8GB 物理内存直接变成 1TB 内存。

### “重启会删除照片，因为内存会被清空”

重启会结束当前运行的程序，并重新建立 RAM 中的运行状态。保存在内部存储、SSD 或 HDD 中的照片和文档不会因此被正常删除。

系统可能在重启或维护时清理少量临时数据，但这和清空照片、文档不是一回事。

### “清理内存”一定是在做同一件事

不一定。

有的“清理内存”按钮会关闭后台程序，释放 RAM。有的清理工具会删除缓存、安装包或下载文件，释放内部存储。还有一些工具会同时执行两种操作。

点击之前，先看页面准备关闭哪些程序、删除哪些文件，以及删除后能否恢复。

## 怎样判断是哪一种空间不足

先看提示中提到了什么：

- 提到照片、视频、下载、文件、安装应用或磁盘空间，通常是**内部存储不足**。
- 提到程序无法运行、后台应用被关闭，或者系统明确显示 RAM 使用量，通常是**内存不足**。
- 电脑显示 C 盘、D 盘、SSD 或 HDD 空间不足，指的是**存储空间不足**。

你还可以观察处理办法：

- 删除文件后，剩余空间增加了，说明你释放的是存储空间。
- 关闭程序后，RAM 占用下降了，说明你释放的是内存。

系统和清理软件偶尔会使用含糊的名称。只要页面显示了具体对象，就优先判断它在处理“正在运行的程序”，还是“已经保存的文件”。

## 一张表看懂区别

| 名称        | 主要用途                       | 断电或正常关机后     | 常见容量示例      | 空间不足时通常怎么处理                               |
| ----------- | ------------------------------ | -------------------- | ----------------- | ---------------------------------------------------- |
| 内存（RAM） | 放置程序运行时正在使用的数据   | 当前数据不会长期保留 | 8GB、16GB、32GB   | 关闭不需要的程序，减少同时运行的任务，或升级物理内存 |
| 内部存储    | 保存设备内部的应用、照片和文件 | 数据继续保留         | 128GB、256GB、1TB | 删除或转移文件，卸载应用，扩充存储                   |
| SSD         | 一种长期存储设备               | 数据继续保留         | 512GB、1TB、2TB   | 删除或转移文件，或更换、增加存储设备                 |
| HDD         | 一种使用机械结构的长期存储设备 | 数据继续保留         | 1TB、2TB、4TB     | 删除或转移文件，或更换、增加存储设备                 |

最后再看一次 `12GB + 256GB`：前者通常决定程序运行时有多少工作空间，后者通常决定你能保存多少应用和文件。两个数字都重要，但不能互相替代。
